# Saved website content

`snapshot.json` is generated by `pnpm content:sync` from public entries in the configured Notion Blog Posts and Projects collections. It stores normalized bodies, article/project metadata, stable route assignments and aliases, media descriptors, bookmarks, and tweets. Treat it as a generated, versioned artifact and commit it with `public/search-index.json`.

Edit source content in Notion, then sync explicitly. Application-authored page copy stays in the app. Builds and page rendering read the snapshot without Notion or S3 credentials; original and optimized media live in immutable R2 objects.

See [the sync guide](../docs/content-sync.md) for setup, selection flags, publication rules, and failure recovery. Use `pnpm content:search` to regenerate only the search index from the local snapshot.
