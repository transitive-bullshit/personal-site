# Saved website content

`snapshot.json` is generated by `pnpm content:sync` from the selected public pages in the top-level Notion Blog Posts collection. Treat it as a read-only, versioned content artifact and commit it with the application.

The snapshot owns normalized article bodies, stable path assignments and aliases, media descriptors, and saved tweets. The app uses it without Notion or S3 credentials. Original and optimized media are immutable R2 objects, not repository files.

Make article edits in Notion and sync explicitly. Keep application-authored content in the app. See [the sync guide](../docs/content-sync.md) for setup, flags, lifecycle behavior, and failure recovery.
